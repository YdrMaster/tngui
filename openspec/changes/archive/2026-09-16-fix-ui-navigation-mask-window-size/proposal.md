## Why

密态推理页的“前往设置”只弹提示，与概览页的可跳转行为不一致；设置页 API Key 当前变成明文输入、入口信息卡出现误导性的“仅配置摘要”状态行，且默认 900×720 窗口低于全局最小内容宽度， 造成 控件挤压和滚动条。需要统一导航语义、恢复凭据遮罩、修正误导性视觉并提高首开可用性。

## What Changes

- 密态推理视图不可发送时的“前往设置”改为直接切换到设置视图，不显示“请点击左侧导航「设置」”的提示弹窗。
- 设置页 API Key 改为默认遮盖显示、支持一次性显隐切换的密码式输入，凭据继续保留在 GUI 会话内存中，不写配置。
- 概览入口信息卡删除“⚪仅配置摘要”状态行，入口模式、绑定地址、本机端口三行上移；该卡继续不承载任何运行或健康状态。
- 放大默认桌面窗口逻辑尺寸为 1440×960，设置最小逻辑窗口 1120×720，并降低全局内容最小宽度。
- 压缩设置页与相关表单/展示区的固定宽和高需求，减少默认窗口下横向滚动与控件截断；不改变任何配置序列化、启动校验或状态判定语义。
- **BREAKING**：设置页 API Key 的规格从“普通文本输入、不得遮罩”改为“默认遮罩且允许显隐切换”。

## Capabilities

### New Capabilities

- 无：不新增规格能力，仅在既有 GUI 能力内调整行为与呈现约束。

### Modified Capabilities

- `gui-shell`: 修改“密态推理凭据只在 GUI 会话内”，新增或调整密态推理页设置跳转、桌面窗口初始尺寸/最小尺寸与紧凑表单约束。

## Impact

- 前端行为与布局：`InferenceView.vue`、`SettingsView.vue`、`IngressInfoCard.vue`、`EntryEditor.vue`、`FieldRenderer.vue`、`App.vue`、`theme.css`。
- 桌面窗口配置：`tauri.conf.json`。
- 行为规格与用户文档：OpenSpec `gui-shell` delta 及 `docs/tngui-ui-guide.md`。
- 不修改 tngui 后端启动、状态轮询、反向代理、TNG 配置序列化或导入导出逻辑。
