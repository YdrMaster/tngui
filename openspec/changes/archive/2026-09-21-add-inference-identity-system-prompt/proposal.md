# Proposal

## Why

密态推理调试页缺少一个让模型明确知道自己运行在蚂蚁密算可信执行环境中的调试辅助。调试者需要用一个可控、可编辑的身份提示词快速验证模型在密态推理身份与安全边界下的回答行为，而不影响其他客户端接入本机反向代理的通用行为。

## What Changes

- 在“密态推理”请求调试页的模型选择控件与思考强度控件之间新增身份注入控件组：
  - “注入身份” toggle，默认开启。
  - “编辑身份” button，点击后在按钮下方展开/收起身份提示词编辑框。
- “注入身份”开启时，只有通过密态推理调试页发送的请求会在 `messages` 最前面追加一条 `role: "system"` 的身份提示词；关闭时不追加。
- 身份提示词默认为一段详细文案，说明：
  - agent 由蚂蚁密算公司提供的密态推理方案驱动；
  - 模型路由服务与推理计算发生在可信执行环境；
  - 运行环境通过远程证明报告验证；
  - 用户数据处理对宿主机、平台运维人员与硬件管理员保持保密；
  - 不虚构具体硬件、证明服务或实现细节。
- 编辑框宽度采用固定 `480px`，高度随内容自动增长，最小 4 行、最大 12 行，超过后内部滚动。
- 身份注入开关、编辑框展开状态与提示词内容仅保存在 GUI 进程内存中：
  - 应用内页面切换时保留；
  - 请求进行中修改只影响下一次发送；
  - GUI 进程退出后重置为默认值；
  - 不写入设置缓存、TNG 配置或任何文件。
- 不修改反向代理行为。直接连接本机反向代理的外部客户端请求仍按现有规则原样透传，不做任何 system message 注入。

## Capabilities

### New Capabilities

- 无。

### Modified Capabilities

- `gui-shell`: 密态推理调试页新增调试专属身份提示词注入能力；调试页页内状态保留范围扩展到身份注入状态，同时保持反向代理对直接请求的通用透传行为不变。

## Impact

- 前端：
  - `frontend/src/views/InferenceView.vue`：新增身份注入控件、默认提示词、编辑框状态与请求组装逻辑。
  - `frontend/src/assets/theme.css`：新增身份控件与编辑框布局样式。
  - `frontend/src/tauri.ts` 与相关测试：为推理命令增加身份提示词参数。
- 后端：
  - `frontend` 调用的 Tauri 命令与 `tngui-core/src/inference.rs` 请求 body 组装逻辑需支持可选身份提示词，但保持 `user` / `assistant` 聊天历史边界不变。
  - `src/lib.rs` 中的推理命令参数需同步调整。
- 文档与测试：
  - `docs/tngui-ui-guide.md` 需补充请求调试页的注入身份控件。
  - 前端组件测试、Tauri 封装测试与 Rust 推理请求测试需覆盖默认开启、关闭、编辑、下一轮生效、页内保留与反代透传不变。
- 明确不改：
  - 反向代理的 body 透传、路径注入规则；
  - 设置页、设置缓存与 TNG 配置；
  - 模型发现、模型选择与发送门锁。
