# Proposal

## Why

密态推理调试页目前没有用户主动切断后续请求上下文的入口。用户完成或中断一组验证后，下一轮请求仍会携带既有历史；目前无法在保留调试轨迹的情况下开始新的后台对话。

## What Changes

- 将应用发布版本从 `0.4.8` 升至 `0.4.9`，并保持 Cargo workspace / Cargo lockfile 与 frontend npm package 元数据版本一致。
- 在密态推理页聊天输入框左侧新增红色“重置”按钮。
- 点击“重置”不移除 UI 中的既有聊天消息，而是在当前消息流末尾插入低对比度“新对话”分隔线。
- 后续 assistant 请求的 `messages` 只包含最近一次分隔线之后的新对话轮次，不再携带重置前的历史上下文；模型、模型清单、选中模型、思考强度、身份注入设置、未发送草稿和页面状态保持不变。
- 必须存在距最近分隔线之后的新用户或 assistant 消息才允许再次重置；因此分隔线可以多次插入，但不会连续叠加。
- 进行中推理请求禁用“重置”；用户先通过既有“停止”动作进入终态。
- 不新增持久化行为，也不新增系统级确认弹窗。

## Capabilities

### New Capabilities

<!-- 无 -->

### Modified Capabilities

- `gui-shell`: 为密态推理多轮对话界面新增用户触发的对话上下文重置行为，并约束可重置条件、UI 历史保留范围、请求上下文边界和新对话分隔显示。

## Impact

- 版本号和 lockfile 元数据推进并入本变更，不另开 bump 变更。
- 主要影响 `frontend/src/views/InferenceView.vue` 的聊天消息模型、重置交互和发送前上下文构建。
- 可能影响聊天区域样式与相关组件测试。
- 不改变推理请求协议、后端命令、TNG 配置、设置缓存或任何文件落盘行为。
