## Purpose

定义 TNG 首页入口状态的可见卡组、状态语义、判定来源和禁止展示的健康表达，避免把本地配置、本地可达或就绪探针误读为远端链路与证明状态。

## ADDED Requirements

### Requirement: 首页四卡布局与入口信息语义

系统须（SHALL）在首页按以下顺序呈现四张卡片：运行状态、入口信息、远端链路、远端证明，并在页面底部保留"原始状态数据"和"进程日志"两个调试面板。入口信息卡只展示入口模式、监听地址和监听端口，不展示状态点，不表达可达性或健康状态。

#### Scenario: 首页布局

- **WHEN** 用户打开首页
- **THEN** 界面按顺序显示运行状态、入口信息、远端链路、远端证明四张卡片，并在页面底部显示原始状态数据和进程日志两个调试面板

#### Scenario: 入口信息只读配置摘要

- **WHEN** 系统渲染入口信息卡
- **THEN** 只显示入口模式、监听地址和监听端口，且不显示"可达""健康""正常""错误"等可达性或健康表达

### Requirement: 运行状态模型

系统须（SHALL）把运行状态收敛为互斥的关停 / 运行 / 错误三态：控制面不可达或进程未运行时显示橙色"关停"；就绪探针通过时显示绿色"运行"；服务失败或进程异常时显示红色"错误"。

#### Scenario: 进程未运行

- **WHEN** TNG 控制面不可达或进程未运行
- **THEN** 运行状态卡显示橙色"关停"

#### Scenario: 服务就绪

- **WHEN** 就绪探针返回成功
- **THEN** 运行状态卡显示绿色"运行"

#### Scenario: 服务或进程异常

- **WHEN** 控制面或日志报告服务失败，或进程异常退出
- **THEN** 运行状态卡显示红色"错误"

### Requirement: 远端链路状态模型

系统须（SHALL）把远端链路收敛为互斥的未初始化 / 已建联 / 失败三态：尚无成功的远端密钥配置时显示灰色"未初始化"；已有远端公钥时显示绿色"已建联"；状态接口或日志报告密钥配置或隧道失败时显示红色"失败"。系统不得把就绪探针或本地入口信息用作远端链路证据。

#### Scenario: 尚无远端密钥

- **WHEN** ingress OHTTP keys 状态没有可用的远端公钥
- **THEN** 远端链路卡显示灰色"未初始化"

#### Scenario: 已有远端公钥

- **WHEN** ingress OHTTP keys 状态包含远端公钥
- **THEN** 远端链路卡显示绿色"已建联"

#### Scenario: 远端链路失败

- **WHEN** 只读状态或进程日志报告密钥配置或隧道失败
- **THEN** 远端链路卡显示红色"失败"

### Requirement: 远端证明状态模型

系统须（SHALL）把远端证明收敛为互斥的未获取 / 已验证 / 待刷新 / 失败四态：无缓存校验凭据时显示灰色"未获取"；有已验证并缓存的校验凭据时显示绿色"已验证"；凭据接近过期时显示橙色"待刷新"；日志报告校验、刷新或取证失败时显示红色"失败"。系统不得把就绪探针、本地可达性或 OHTTP access log 中固定为 false 的 `attested` 字段当作远端证明状态。

#### Scenario: 无缓存凭据

- **WHEN** ingress OHTTP keys 状态没有缓存的校验凭据
- **THEN** 远端证明卡显示灰色"未获取"

#### Scenario: 凭据已验证

- **WHEN** ingress OHTTP keys 状态包含已验证并缓存的校验凭据
- **THEN** 远端证明卡显示绿色"已验证"

#### Scenario: 凭据待刷新

- **WHEN** 可用证据显示校验凭据接近过期
- **THEN** 远端证明卡显示橙色"待刷新"

#### Scenario: 凭据失败

- **WHEN** 进程日志或状态接口报告校验、刷新或取证失败
- **THEN** 远端证明卡显示红色"失败"

### Requirement: 状态视觉与禁止表达

系统须（SHALL）按指定 HTML 设计稿实现卡片位置、文案、状态图例、色点颜色和卡片布局：绿色表示已成功，橙色表示关停或待刷新，红色表示失败，灰色表示未初始化或未获取，入口信息卡不使用状态颜色。首页不得新增一站式"远端健康正常"绿灯，不得显示本地访问可达或本地访问错误，不得明示或暗示入口信息代表业务可达。

#### Scenario: 状态色点与文字

- **WHEN** 任一状态卡渲染状态
- **THEN** 同时显示设计稿定义的颜色色点和状态文字

#### Scenario: 禁止一站式远端健康表达

- **WHEN** 远端链路与远端证明同时成功
- **THEN** 首页仍只分别展示两张成功卡，不新增"远端健康正常"一站式绿灯

#### Scenario: 不展示本地访问可达性

- **WHEN** 系统渲染入口信息卡或任何首页卡片
- **THEN** 界面不显示本地访问可达或本地访问错误
