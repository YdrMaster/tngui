## Why

设置页与密态推理页仍然包含大量占位控件、重复说明和与概览不同源的状态摘要，容易误导用户；发送请求的输入框几何和按钮对齐也存在可感知的交互瑕疵。此项调整在不动推理链路语义的前提下精简 UI，并补齐真实的日志导出能力。

## What Changes

- 密态推理页“输入内容”textarea 改为按内容自动增高，禁用手动 resize；为避免无限撑开页面，最大行数有界。
- 对齐“发送测试请求”按钮内的图标与文字；移除按钮下遗留的蓝色锁形提示框。
- 设置页“密态推理”卡只保留普通文本输入的 API Key；不再提供密码式显隐切换、保存并验证、复制本地 URL、导入配置、导出配置、清除本机凭据及相关说明。
- 将设置页“高级 TNG 配置”标题改为“TNG 配置”。
- 移除 TNG 配置区的保存按钮；用户从设置视图切换到其他视图时自动保存并按既有语义决定是否重启，成功或不变化时静默处理。
- 客户端信息只显示客户端版本和操作系统，移除“更新通道 稳定版(OTA)”。
- “导出日志”从占位改为真实功能：弹出原生保存位置选择框，将概览“进程日志”展示的 TNG stdout/stderr 快照写入用户选择路径。
- 设置页 TNG Gateway 区域改为展示与概览第 1、3、4 张卡片相同的状态卡：运行状态、远端链路、远端证明；复用同一状态推导，不包含入口信息卡。

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- `gui-shell`: 修改密态推理请求面板、设置页密态推理凭据、TNG 配置自动保存、设置页网关状态、客户端信息与 TNG 日志导出的用户可见行为要求。

## Impact

- 前端：`frontend/src/views/InferenceView.vue`、`frontend/src/views/SettingsView.vue`、`frontend/src/views/Overview.vue`、可能新增共享状态视图 helper、`frontend/src/tauri.ts` 和相关样式。
- Tauri 命令：新增一个安全的日志文本写入命令，用于保存当前进程输出快照。
- 文档：`docs/tngui-ui-guide.md` 同步设置页和密态推理页描述。
- 不修改推理发送协议、TNG 配置序列化格式、反代行为或 TNG 启停语义。
